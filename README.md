# Descrição da Atividade: #

Este projeto apresenta uma atividade prática de Análise de Dados aplicada ao setor de energia, utilizando diferentes conjuntos de dados relacionados ao consumo e à geração de energia.
A atividade tem como objetivo aplicar os conhecimentos trabalhados em aula para preparar, inspecionar, manipular e interpretar dados, utilizando as ferramentas Orange Data Mining e Python com a biblioteca Pandas.

O trabalho é composto por seis datasets, cada um representando um contexto diferente do setor energético:

- Appliances Energy Prediction;
- Steel Industry Energy Consumption;
- Power Consumption of Tetouan City;
- Solar Power Generation Data;
- Wind & Solar Energy Production Dataset;
- Individual Household Electric Power Consumption;

Cada conjunto de dados possui uma situação específica de análise e diferentes critérios para seleção e interpretação dos registros.

# Objetivos: #

- Carregar e inspecionar conjuntos de dados;
- Identificar e tratar valores ausentes quando necessário;
- Selecionar os atributos relevantes para cada análise;
- Criar amostras dos datasets utilizando o Orange Data Mining;
- Exportar os dados preparados para arquivos CSV;
- Utilizar Python e Pandas para manipulação dos dados;
- Calcular valores máximos, médias e percentuais;
- Criar filtros utilizando diferentes condições;
- Comparar conjuntos de registros;
- Interpretar os resultados considerando o contexto energético de cada dataset.

A atividade não tem como foco a aplicação de modelos de aprendizado de máquina, mas sim a preparação, manipulação e interpretação inicial dos dados.
